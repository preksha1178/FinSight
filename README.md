# 📊 FinSight — AI Financial Advisor for Indian SMEs

A final year BCA project that combines data analysis, 
AI, and business intelligence to help small businesses 
make smarter financial decisions.

## 🚀 Features
- 📊 Auto-generated financial dashboard
- 📋 Profit & Loss statement
- 🏢 Company health & position scoring
- 🔮 3-month revenue forecast using ML
- 📧 Automated email alert system
- 🤖 AI-powered financial advisor chatbot

## 🛠️ Tech Stack
- Python
- Streamlit
- Pandas
- Plotly
- Scikit-learn
- Groq AI (LLaMA3)
- SQLite

## ▶️ How to Run
pip install -r requirements.txt
streamlit run app.py
